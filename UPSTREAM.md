This repository is an independent repository for the **Random Downloads** Mihon extension.

It vendors the build infrastructure and shared utility code needed by the extension from:

- **Keiyoushi extensions-source**
- Upstream repository: https://github.com/keiyoushi/extensions-source
- Baseline snapshot: `62a33ed2cbf449d39f979d9cb7b698752b8a71a3`
